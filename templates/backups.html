📘 Guide en 3 étapes : Comment obtenir vos identifiants Google Drive (100% Gratuit)

Étape 1 : Rendez-vous sur la Google Cloud Console ↗ avec votre compte Gmail / Google Workspace.

Étape 2 : Créez un nouveau projet (ex: Institut-ILAS-Backup), puis activez l'API Google Drive dans APIs & Services > Library.

Étape 3 : Allez dans APIs & Services > Credentials, cliquez sur Create Credentials > OAuth client ID (Type : Web application). Ajoutez dans les URLs de redirection :
{{ request.url_root }}settings/gdrive/callback et http://localhost:8080/settings/gdrive/callback.
Téléchargez le fichier JSON ou copiez le Client ID et Client Secret dans le formulaire ci-dessus, puis cliquez sur Enregistrer et Se Connecter avec Google Drive !
